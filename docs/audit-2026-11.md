# Codebase audit, November 2026

A read of the whole repository from four angles on 13 November 2026, before a large refactor: the core, the panels, the contract with its hosts and server, and the tests with the docs. About 41,000 lines of TypeScript. Line numbers are as they stood that day, before the refactor moved things.

What was done about each finding is in the last column of each table: **fixed** in the refactor that followed, or **tracked** as an issue. [ARCHITECTURE.md](ARCHITECTURE.md) describes the code as it stands now, and [features.md](features.md) is the map of features the issues hang from.

## How it was read

| Angle | Question |
|---|---|
| Shape | Where is the code that does more than one job, and what would it take to split it? |
| Sameness | What is written more than once, and does one copy disagree with another? |
| Seams | Do the boundaries the project declares hold in practice, or only in the letter? |
| Words | Does one thing have one name, in the code and in what people read? |
| Safety | What does the code trust that it shouldn't, and what does it lose silently? |
| Proof | Which features are tested at which level, and which tests can't be trusted? |
| Truth | Do the docs still describe the code? |

## Patterns to keep

These are what made the day's other work safe. New code should follow them.

1. **The record log is the only truth, and state is a pure fold over it.** Every rule about who may change what lives in `foldRecords`, so every reader of a vault applies it.
2. **One contract, many hosts.** A panel never knows which app it is in. A host never knows what a feature does.
3. **Network access is one injected `fetch`, and time and chance are injected too.** That is what let four vaults run in one process and replay byte for byte.
4. **Boundaries are checked by a script,** and the dependency matrix fails on a cycle.
5. **A feature is a function of a context** that returns its handlers. Nothing reaches a feature except through that.
6. **Tests drive real things:** the real core, the real server, the real Obsidian. A stand-in is used only for what can't be had, and says so.
7. **Rules are stated in plain words above the code that keeps them,** and the simulation's expectations are sentences a person can read.
8. **Refuse on the safe side and say so.** An unsigned record from a labmate is refused, and the Lab tab names whose.

## Patterns to end

| # | Pattern | Why it hurts | Where it is worst |
|---|---|---|---|
| 1 | **A file that is a whole layer.** | Nothing in it can be read, tested or changed alone | `core/index.ts` (1,905 lines), `canvas/App.tsx` (2,307), `contract/records.ts` (1,624), `obsidian/main.ts` (1,356) |
| 2 | **Wiring by a variable filled in later.** | Order of construction is load-bearing and nothing says so | Five `let` hooks in `core/index.ts` |
| 3 | **Two shapes for one kind of module.** | A hook leaked into the handler map and nobody saw | Seven of twenty features |
| 4 | **Reading the graph past the helper that knows the rule.** | A type that gave way to the lab's, or a removed unit, is read wrongly | About twenty sites |
| 5 | **The same small helper, again.** | Copies drift: file sizes are counted in 1000s in two panels and 1024s in a third | Base64 seven times, plurals seven, dates five, trailing-slash trim ten |
| 6 | **One idea, several names.** | Nobody can guess a method's name, and people read "node" where the product says "unit" | `node.*`, `unit.*`, `units.*`; five names for one id parameter |
| 7 | **A shape declared on both sides of a wire.** | The two sides already disagree | Client and server: twelve shapes, every route path three times |
| 8 | **A failure nobody hears about.** | A share that failed looks like one that worked | About forty calls in panels, a handful in the core |
| 9 | **A cast that hides a gap in a type.** | The gap stays | `as never` to make a canvas edge, and to clear a field |
| 10 | **Test scaffolding copied into each test.** | Twenty-two copies to change when the core's start-up changes | `test/*.test.ts` |
| 11 | **Sleeping in a test.** | Slow, and flaky on a busy machine | Twelve unit files, most harness scripts |
| 12 | **A test that leaves the vault changed.** | The next run starts from somewhere else | Most harness scripts |
| 13 | **Docs that are notes, kept as if they were reference.** | A reader can't tell what is true now | About half of `docs/` |
| 14 | **A stylesheet that is global by accident.** | `.note` means a sticky note in one file and a hint in another | Ten stylesheets in one bundle |

## What the refactor did not touch, on purpose

- **Renaming the calls** (`node.*` to `unit.*` and the rest). It changes every panel, test and harness script at once and should land alone.
- **Splitting `canvas/App.tsx`.** It needs the writer pulled out first and a real-app run after each step.
- **Retiring the Roam host.** It is a product decision, and the code is not in the way.
- **A schema library and a route table.** Both are in [tooling.md](tooling.md) and both add a dependency.
